# My Portfolio website [deployed](https://viktoriiakuznetsova.vercel.app/)

![App demo](./demo.gif)

## About

This website showcases my projects, skills, and experience as a developer. It includes interactive project cards, smooth animations, and a user-friendly interface. The goal of this portfolio is to provide a clear overview of my work while demonstrating modern web development practices.

## Features

- 🎯 **Modern Design** - Clean and professional UI with smooth animations
- 🌐 **Bilingual** - Full support for English and Russian languages
- 📱 **Fully Responsive** - Optimized for all devices and screen sizes
- ♿ **Accessible** - Follows WCAG guidelines
- 🎬 **Interactive Elements** - Typewriter effects, marquee, and animated components
- 🎨 **Typography Engine** - Custom typography with non-breaking spaces and smart quotes + Jest tests

## 🛠️ Tech Stack

### Core

- **React 19** - Latest React with concurrent features
- **TypeScript 5.8** - Type-safe development
- **Vite 7** - Lightning-fast build tool and dev server

### UI & Styling

- **Vanilla CSS** - Custom styling with modern CSS features
- **React Icons** - Comprehensive icon library
- **React Fast Marquee** - Smooth marquee animations
- **React Simple Typewriter** - Typewriter effect component

## Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/vkuznets23/portfolio.git
   cd portfolio/my-portfolio
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

## 📜 Available Scripts

| Command         | Description                              |
